Doctrine

I build software that runs on your machine, not someone else’s.

Method Four positions
01

The machine is yours

A local assistant, a resolver you operate, a camera that answers to you. Most software would rather be a client to somebody else’s server. Mine tries not to be.

02

Defaults are a proposal

A new tab page, a downloader, a status line, an operating system. Every one of these arrived as somebody’s guess about what you wanted. They are all editable.

03

Go where the problem lives

Python for reach, Go for services, Rust for the parts that must not fail, C# and Swift because that is where the platform is. The language is a consequence, not an identity.

04

Ship it, then say what it is

Every object in this catalogue is a repository you can clone and run right now. None of it is a mockup, and none of it is waiting on permission.

Trajectory 2022 → now
  1. 2022 first repository

    A script, and a question

    token-vc-joiner — one Python file poking at Discord to see what it would let me do. Everything after this is that same question asked more carefully.

  2. 2025 8 repositories

    NullStudio

    A framework, then a tracker, then moderation, then a release channel and a storefront. The year the work stopped being scripts and started being infrastructure that other things depend on.

  3. 2026 12 repositories

    Down the stack

    Go for a resolver, Rust for a compiler, C# against the capture path, Swift over a Bluetooth mesh, PyTorch on local weights. The year the questions moved below the application layer.
